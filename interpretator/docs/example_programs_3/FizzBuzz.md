FizzBuzz — читает число за числом в цикле и далее печатает:
“Fizz”, если число делится на 3
“Buzz”, если делится на 5
“FizzBuzz”, если число делится и на 3, и на 5
Само число в остальных случаях
```
НАЧАЛО
    ЧИСЛО n : ДРОБЬ;
    МОЛВИ("Введите количество чисел для FizzBuzz: ");
    ВНЕМЛИ(n);
    
    ФУНКЦИЯ fizzBuzzДляЧисла(число: ЧИСЛО) : СТРОКА
    НАЧАЛО
        БУЛЕВО делитсяНа3 = (число % 3 == 0);
        БУЛЕВО делитсяНа5 = (число % 5 == 0);
        
        ЕСЛИ (делитсяНа3 @ делитсяНа5) СТАЛОБЫТЬ
        НАЧАЛО
            ДАРОВАТЬ "FizzBuzz";
        ИСХОД
        ИНО
        НАЧАЛО
            ЕСЛИ (делитсяНа3) СТАЛОБЫТЬ
            НАЧАЛО
                ДАРОВАТЬ "Fizz";
            ИСХОД
            ИНО
            НАЧАЛО
                ЕСЛИ (делитсяНа5) СТАЛОБЫТЬ
                НАЧАЛО
                    ДАРОВАТЬ "Buzz";
                ИСХОД
                ИНО
                НАЧАЛО
                    ДАРОВАТЬ число_в_строку(число);
                ИСХОД
            ИСХОД
        ИСХОД
    ИСХОД
    
    МОЛВИ("FizzBuzz от 1 до ", n, ":");
    ЧИСЛО i : ДРОБЬ = 1;
    
    ПОКУДА (i <= n) ТВОРИ
    НАЧАЛО
        СТРОКА результат = fizzBuzzДляЧисла(i);
        МОЛВИ(результат);
        i = i + 1;
    ИСХОД
ИСХОД
```
