# Семантика типов данных языка RusMatushka

## Поддерживаемые типы данных

### 1. Числовые типы
| Тип                      | Ключевое слово  | Описание							| Примеры				|
|--------------------------|-----------------|----------------------------------|-----------------------|
| Число с плавающей точкой | `ДРОБЬ`		 | 64-битное число двойной точности | `3.14`, `-2.5`, `0.0` |

### 2. Строковый тип
| Тип	 | Ключевое слово | Описание						  | Примеры									  |
|--------|--------------- |-----------------------------------|-------------------------------------------|
| Строка | `СТРОКА`		  | Строка символов в кодировке UTF-8 | `"Привет"`, `""`, `"строка\н"` |

### 3. Логический тип
| Тип		 | Ключевое слово | Описание			| Литералы		   |
|------------|--------------- |---------------------|------------------|
| Логический | `БУЛЕВО`		  | Логическое значение | `ИСТИНА`, `ЛОЖЬ` |

### 4. Пустой тип (void)
| Тип	 | Ключевое слово| Описание							 | Использование	   |	
|--------|---------------|-----------------------------------|---------------------|
| Пустой | (отсутствует) | Отсутствие возвращаемого значения | Функции без `: тип` |

## Объявление и инициализация переменных

### Синтаксис:
	ЧИСЛО цена : ДРОБЬ = 99.99; 
	СТРОКА имя = "Иван"; 
	БУЛЕВО готово = ИСТИНА;

### Правила инициализации:
1. Переменные должны быть инициализированы перед использованием
2. Тип выражения должен соответствовать объявленному типу переменной
3. Неявное приведение типов запрещено

## Типизация выражений

### Арифметические операции:
| Операция    | Типы операндов		| Тип результата		  |
|-------------|---------------------|-------------------------|
| `+ - * / %`   | `ДРОБЬ`, `ДРОБЬ`	| `ДРОБЬ`				  |
| `+`		  | `СТРОКА`, `СТРОКА`  | `СТРОКА` (конкатенация) |

### Операции сравнения:
| Операция			| Типы операндов     | Тип результата |
|-------------------|--------------------|----------------|
| `== != < > <= >=` | `ДРОБЬ`, `ДРОБЬ`   | `БУЛЕВО`		  |
| `== !=`			| `СТРОКА`, `СТРОКА` | `БУЛЕВО`		  |
| `== !=`			| `БУЛЕВО`, `БУЛЕВО` | `БУЛЕВО`		  |

### Логические операции:
| Операция | Типы операндов		| Тип результата |
|----------|--------------------|----------------|
| `@ || !` | `БУЛЕВО`, `БУЛЕВО` | `БУЛЕВО`		 |

## Типы функций

### Функции с возвращаемым значением:
```
	ФУНКЦИЯ сумма(а: ДРОБЬ, б: ДРОБЬ) : ДРОБЬ
	НАЧАЛО
	ДАРОВАТЬ а + б;
	ИСХОД
```

### Функции без возвращаемого значения (void):
```
	ФУНКЦИЯ приветствие(имя: СТРОКА)
	НАЧАЛО
	МОЛВИ("Привет, ", имя);
	// ДАРОВАТЬ; // опционально
	ИСХОД
```

### Правила:
1. Функция без `: тип` имеет пустой тип возврата
2. Пустая функция может использовать `ДАРОВАТЬ` без выражения
3. Функция с типом возврата должна возвращать значение через `ДАРОВАТЬ выражение`
4. Все ветки выполнения должны возвращать значение совместимого типа

## Семантические правила типов

### 1. Совместимость присваивания
```
	ЧИСЛО y : ДРОБЬ = 3.14;      
	СТРОКА строченька = "абоба"
	y = 5.0;                       // Ok
	y = строченька				   // Ошибка ДРОБЬ != СТРОКА
```

### 2. Условные выражения
```
	ЕСЛИ (x > 0)                 // x должен быть числовым типом
	ЕСЛИ (готово)                // готово должен быть БУЛЕВО
```
### 3. Циклы
```
	ПОКУДА (ИСТИНА)              // OK: БУЛЕВО
	ПОКУДА (x < 10)              // OK: сравнение возвращает БУЛЕВО
	ПОКУДА (1)                   // Ошибка: число вместо БУЛЕВО
```
### 4. Встроенные функции
```
	модуль(-5)                   // Возвращает ДРОБЬ в зависимости от аргумента
	малое(1.00, 2.00, 3.00)              // Все аргументы должны быть одного числового типа
```
### Обработка ошибок типов
	Несоответствие типов при присваивании - ошибка компиляции

	Использование неинициализированной переменной - ошибка компиляции

	Неявное приведение типов - ошибка компиляции

	Отсутствие возврата в функции с типом - ошибка компиляции

	Возврат несовместимого типа - ошибка компиляцииs
