**Список тестов семантики**

**Область видимости**
- [ ] Обращение к переменной вне её области видимости
- [ ] Локальная переменная функции недоступна после её завершения
- [ ] Функция видит переменные внешней области

**Уникальность имён**
- [ ] Две переменные с одинаковым именем в одной области
- [ ] Две переменные с одинаковым именем в разных областях
- [ ] Переменная и функция с одинаковым именем в разных областях
- [ ] Переменная с именем встроенной функции
- [ ] Переменная с именем типа данных
- [ ] Внутренняя переменная скрывает внешнюю
- [ ] Параметр и локальная переменная с одинаковым именем в функции

**Параметры функций**
- [ ] Передача параметров по значению
- [ ] Указание типа параметра при объявлении
- [ ] Несоответствие количества параметров
- [ ] Несоответствие типа параметра
- [ ] Несоответствие порядка параметров
- [ ] Присваивание параметру нового значения
- [ ] Функция с возвращаемым типом заканчивается ДАРОВАТЬ выражение
- [ ] Функция без типа заканчивается без ДАРОВАТЬ
- [ ] Функция без типа заканчивается ДАРОВАТЬ;
- [ ] Функция с возвращаемым типом без ДАРОВАТЬ
- [ ] Void-функция пытается вернуть значение
- [ ] Void-функция используется как выражение

**Рекурсия**
- [ ] Функция вызывает саму себя
- [ ] Две функции вызывают друг друга
- [ ] Взаимная рекурсия в одной области видимости
- [ ] Взаимная рекурсия в разных областях видимости

**Ветвления**
- [ ] Булево условие в ЕСЛИ
- [ ] Небулево условие в ЕСЛИ
- [ ] Выполнение блока после СТАЛОБЫТЬ при истине
- [ ] Выполнение блока после ИНО при лжи
- [ ] Явный блок НАЧАЛО...ИСХОД после СТАЛОБЫТЬ
- [ ] Явный блок НАЧАЛО...ИСХОД после ИНО
- [ ] Отсутствие явного блока после СТАЛОБЫТЬ
- [ ] Отсутствие явного блока после ИНО

**Циклы**
**Цикл ПОКУДА**
- [ ] Выполнение при истинном условии
- [ ] Булево условие
- [ ] Небулево условие
- [ ] Вычисление условия перед каждой итерацией
- [ ] Цикл не выполняется при ложном условии с начала

**Цикл ДЛЯ**
- [ ] Создание переменной в области цикла
- [ ] Вычисление выражений ОТ и ДО один раз
- [ ] Переменная изменяется от начального до конечного включительно
- [ ] Проверка превышения конечного значения
- [ ] Тип ДРОБЬ для переменной цикла и границ
- [ ] Нечисловой тип для границ цикла

**Операторы управления циклами**
- [ ] ВЫЙТИ внутри цикла
- [ ] ПРОДОЛЖИТЬ внутри цикла
- [ ] ВЫЙТИ вне цикла
- [ ] ПРОДОЛЖИТЬ вне цикла

**Присваивания**
- [ ] Идентификатор переменной в левой части
- [ ] Присваивание литералу
- [ ] Присваивание вызову функции
- [ ] Присваивание выражению
- [ ] Проверка совместимости типов при присваивании
- [ ] Несовместимость типов при присваивании
- [ ] Изменение типа переменной после объявления

**Инициализация переменных**
- [ ] Обращение к неинициализированной переменной
- [ ] Явная инициализация переменной перед использованием
- [ ] Параметры функций считаются инициализированными
- [ ] Переменная цикла ДЛЯ инициализируется значением ОТ
