## Ошибки
- [x] Ошибка при незакрытой скобке: `(2 + 3`
- [x] Ошибка при лишней скобке: `2 + 3)`
- [x] Ошибка при неполном выражении: `2 +`
- [x] Ошибка при отсутствии аргументов в функции: `модуль()`
- [x] Ошибка при лишней запятой в аргументах: `малое(1, 2,)`
- [x] Ошибка при отсутствии запятой между аргументами: `малое(1 2)`
- [x] Ошибка при неверном формате числа: `.25`, `3.14.15`

## Разбор переменных дробного типа
Позитивные случаи:
- [x] Разбор выражений с несколькими переменными: `ЧИСЛО x : ДРОБЬ = 25; ЧИСЛО y : ДРОБЬ = 5; ЧИСЛО z : ДРОБЬ = x * y;`, `ЧИСЛО x : ДРОБЬ = 5; ЧИСЛО y : ДРОБЬ = 2; ЧИСЛО z : ДРОБЬ = степень(x, y);`

- [x] Разбор инициализации переменной дробного типа: `ЧИСЛО x : ДРОБЬ = 25.5 * 2.0 / 2.0; МОЛВИ(x);`, `ЧИСЛО x : ДРОБЬ = -4.7; МОЛВИ(x);`
- [x] Разбор присвоения переменной значения: `ЧИСЛО x : ДРОБЬ; y = 555.8; МОЛВИ(y);`

Негативные случаи:
- [x] Разбор инициализации переменной дробного типа строкой: `ЧИСЛО x : ДРОБЬ = "dff"; МОЛВИ(x);`
- [x] Разбор объявления переменной, которая уже объявлена: `ЧИСЛО x : ДРОБЬ; ЧИСЛО x : ДРОБЬ; МОЛВИ(x);`
- [x] Разбор присвоения переменной значения неинициализированной переменной: `ЧИСЛО x : ДРОБЬ; ЧИСЛО y : ДРОБЬ = x; МОЛВИ(y);`

## Разбор ввода/вывода
Позитивные случаи:
- [x] Разбор потока ввода c неинициализированной переменной: `ЧИСЛО x : ДРОБЬ; ВНЕМЛИ(x); МОЛВИ(x);`
- [x] Разбор потока вывода с двумя переменными: `ЧИСЛО x : ДРОБЬ = 10.2; ЧИСЛО y : ДРОБЬ = 12.2; МОЛВИ(x, y);`
- [x] Разбор потока вывода со строкой в начале и множеством чисел: `ЧИСЛО x : ДРОБЬ = 25.5; МОЛВИ(\"Числа: \", x, \", \", x);`;

Негативные случаи:
- [x] Разбор потока ввода с несуществующей переменной: `ВНЕМЛИ(x); МОЛВИ(x);`
- [x] Разбор потока вывода с неинициализированной переменной: `ЧИСЛО x : ДРОБЬ; МОЛВИ(x);`

## Разбор области видимости

**Позитивные случаи:**
- [x] Разбор использования переменной, которая инициализирована в блоке выше: `ЧИСЛО x : ДРОБЬ = 25.5; НАЧАЛО ЧИСЛО y : ДРОБЬ = x; МОЛВИ(y); ИСХОД`

**Негативные случаи:**
- [x] Разбор объявления переменной, которая уже объявлена в блоке выше: `ЧИСЛО x : ДРОБЬ = 25.5; НАЧАЛО ЧИСЛО x; ИСХОД`
- [x] Разбор прекращения действия переменной за областью видимости: `НАЧАЛО ЧИСЛО x : ДРОБЬ = 25.5; ИСХОД МОЛВИ(x);`
- [x] Разбор случая, когда нет ключевого слова 'ИСХОД': `НАЧАЛО ЧИСЛО x : ДРОБЬ = 25.5; МОЛВИ(x);`
