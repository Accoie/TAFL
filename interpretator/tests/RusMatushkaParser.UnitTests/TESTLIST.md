- [x] Разбор инициализации переменной дробного типа: `ЧИСЛО x : ДРОБЬ = 25.5 * 2.0 / 2.0; МОЛВИ(x);`, `ЧИСЛО x : ДРОБЬ = -4.7; МОЛВИ(x);`
- [x] Разбор присвоения переменной значения: `ЧИСЛО x : ДРОБЬ; y = 555.8; МОЛВИ(y);`

Негативные случаи:

- [x] Разбор присвоения переменной значения неинициализированной переменной: `ЧИСЛО x : ДРОБЬ; ЧИСЛО y : ДРОБЬ = x; МОЛВИ(y);`

## Разбор ввода/вывода
Позитивные случаи:
- [x] Разбор потока ввода c неинициализированной переменной: `ЧИСЛО x : ДРОБЬ; ВНЕМЛИ(x); МОЛВИ(x);`
- [x] Разбор потока вывода с двумя переменными: `ЧИСЛО x : ДРОБЬ = 10.2; ЧИСЛО y : ДРОБЬ = 12.2; МОЛВИ(x, y);`
- [x] Разбор потока вывода со строкой в начале и множеством чисел: `ЧИСЛО x : ДРОБЬ = 25.5; МОЛВИ(\"Числа: \", x, \", \", x);`;

- [x] Разбор условия: `ЧИСЛО x : ДРОБЬ = 3; ЕСЛИ (x == 3) СТАЛОБЫТЬ НАЧАЛО МОЛВИ(x); ИСХОД`

## Разбор цикла while
**Позитивные случаи**
- [x] Разбор цикла: `ЧИСЛО x:ДРОБЬ = 0; ПОКУДА(x <= 3) ТВОРИ НАЧАЛО x = x + 1; МОЛВИ(x); ИСХОД` 
- [x] Разбор break: `ЧИСЛО x:ДРОБЬ = 0; ПОКУДА(1) ТВОРИ НАЧАЛО ЕСЛИ (x == 5) СТАЛОБЫТЬ НАЧАЛО ВЫЙТИ; ИСХОД x = x + 1; ИСХОД МОЛВИ(x);`
- [x] Разбор continue: `ЧИСЛО x:ДРОБЬ = 0; ПОКУДА(x < 4) ТВОРИ НАЧАЛО ЕСЛИ (x == 2) СТАЛОБЫТЬ НАЧАЛО ПРОДОЛЖИТЬ; ИСХОД x = x + 1; МОЛВИ(x); ИСХОД`
**Негативные случаи**
- [x] Разбор цикла с break вне цикла: `ЧИСЛО x:ДРОБЬ = 0; ПОКУДА(x < 3) ТВОРИ НАЧАЛО x = x + 1; ИСХОД ВЫЙТИ; МОЛВИ(x);`
- [x] Разбор цикла с continue: `ЧИСЛО x:ДРОБЬ = 0; ПОКУДА(x < 3) ТВОРИ НАЧАЛО x = x + 1; ПРОДОЛЖИТЬ; ИСХОД МОЛВИ(x);`

## Разбор цикла for
**Позитивные случаи**
- [x] Разбор цикла: `ЧИСЛО x : ДРОБЬ = 0; ДЛЯ i ОТ 1 ДО 5 ТВОРИ НАЧАЛО x = x + i; ИСХОД МОЛВИ(x);`
- [x] Разбор вложенного цикла: `ЧИСЛО sum:ДРОБЬ = 0; ДЛЯ i ОТ 1 ДО 3 ТВОРИ НАЧАЛО ДЛЯ j ОТ 1 ДО 2 ТВОРИ НАЧАЛО sum = sum + i * j; ИСХОД ИСХОД МОЛВИ(sum);`
- [x] Разбор цикла в обратном порядке: `ДЛЯ i ОТ 5 ДО 1 ТВОРИ НАЧАЛО МОЛВИ(i); ИСХОД`
- [x] Разбор цикла с break: `ДЛЯ i ОТ 1 ДО 5 ТВОРИ НАЧАЛО ЕСЛИ (i == 3) СТАЛОБЫТЬ НАЧАЛО ВЫЙТИ; ИСХОД МОЛВИ(i); ИСХОД`
- [x] Разбор цикла с continue: `ДЛЯ i ОТ 1 ДО 5 ТВОРИ НАЧАЛО ЕСЛИ (i == 3) СТАЛОБЫТЬ НАЧАЛО ПРОДОЛЖИТЬ; ИСХОД МОЛВИ(i); ИСХОД`
**Негативные случаи**
- [x] Разбор цикла, где счетчик дробное значение: `ЧИСЛО x : ДРОБЬ; ДЛЯ i ОТ 1.1 ДО 5 ТВОРИ НАЧАЛО x = i; ИСХОД МОЛВИ(x);`
- [x] Разбор цикла с break вне цикла: `ДЛЯ i ОТ 1 ДО 5 ТВОРИ НАЧАЛО МОЛВИ(i); ИСХОД ВЫЙТИ;`
- [x] Разбор цикла с continue вне цикла: `ЧИСЛО x : ДРОБЬ; ДЛЯ i ОТ 1 ДО 5 ТВОРИ НАЧАЛО x = i; ИСХОД ПРОДОЛЖИТЬ;`
- [x] Разбор цикла, в котором есть функция, которая вызывает break: `ДЛЯ i ОТ ДО 5 ТВОРИ НАЧАЛО ФУНКЦИЯ sum(x: ДРОБЬ):ДРОБЬ break ДАРОВАТЬ 1; ИСХОД ИСХОД`
