## Ошибки
- [ ] Ошибка при незакрытой скобке: `(2 + 3`
- [ ] Ошибка при лишней скобке: `2 + 3)`
- [ ] Ошибка при неполном выражении: `2 +`
- [ ] Ошибка при отсутствии аргументов в функции: `модуль()`

- [ ] Ошибка при отсутствии запятой между аргументами: `малое(1 2)`
- [ ] Ошибка при неверном формате числа: `3.14.15`
