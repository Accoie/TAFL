# Сравнение синтаксиса выражений в C# и C++
## 1. Сравнение числовых типов данных

### C++:

Целочисленные типы (зависят от платформы)
```
	char           // обычно 1 байт
	short          // обычно 2 байта
	int            // обычно 4 байта
	long           // 4 или 8 байт
	long long      // обычно 8 байт
```
Типы с фиксированным размером (C++11)
```
	int8_t, int16_t, int32_t, int64_t
	uint8_t, uint16_t, uint32_t, uint64_t
```
Вещественные типы
```
	float          // 4 байта
	double         // 8 байт
	long double    // 8, 12 или 16 байт
```
Беззнаковые типы
```
	unsigned int, unsigned long, etc.
```

### C#:

Целочисленные типы (фиксированный размер)
```
	sbyte          // 1 байт со знаком
	byte           // 1 байт без знака
	short          // 2 байта со знаком
	ushort         // 2 байта без знака
	int            // 4 байта со знаком
	uint           // 4 байта без знака
	long           // 8 байт со знаком
	ulong          // 8 байт без знака
```
Вещественные типы
```
	float          // 4 байта
	double         // 8 байт
	decimal        // 16 байт (для финансовых вычислений)
```

### Ключевые различия:

	- C# имеет фиксированные размеры типов независимо от платформы

	- C++ размеры типов зависят от компилятора и платформы

	- C# имеет тип decimal для точных финансовых расчетов

	- В C# все типы являются объектами и имеют методы

## 2. Сравнение арифметических операторов
### Общие операторы:
```
	a + b    // сложение
	a - b    // вычитание
	a * b    // умножение
	a / b    // деление
	a % b    // остаток от деления
	-a       // унарный минус
	+a       // унарный плюс
	++a, a++ // инкремент
	--a, a-- // декремент
```

### Особенности C++: 

указательная арифметика: 
```
	int* ptr = arr;
	ptr + 5;     // арифметика указателей
	ptr1 - ptr2; // разность указателей
```

## 3. Сравнение приоритетов операций

Высокий приоритет одинаков в обоих языках

### Различия:

	В C++ оператор , (запятая) имеет низкий приоритет и может быть перегружен

	В C# оператор ?? (null-coalescing) имеет специальный приоритет

	В C# оператор ?. (null-conditional) имеет высокий приоритет


## 4. Список лево- и правоассоциативных операторов

### Правоассоциативные (одинаково в обоих языках)

присваивание:
```
	=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>= 
```
условный оператор:
```
	?: 
```
### Левоассоциативные (одинаково в обоих языках)

арифметические, битовые сдвиги, сравнение, равенство, логические операции

## 5. Сравнение встроенных функций для работы с числами

C++: используются заголовочные файлы
```
	#include <cmath>
	abs(x) fabs(x)          // модуль
	sqrt(x) pow(x, y)       // корень, степень
	sin(x) cos(x) tan(x)    // тригонометрия
	log(x) log10(x) exp(x)  // логарифмы и экспонента
	ceil(x) floor(x) round(x) // округление

	#include <algorithm>
	max(a, b) min(a, b)     // минимум/максимум
```
C# используется класс Math
```
	using System;
	Math.Abs(x)									// модуль
	Math.Sqrt(x) Math.Pow(x, y)					// корень, степень
	Math.Sin(x) Math.Cos(x) Math.Tan(x)			// тригонометрия
	Math.Log(x) Math.Log10(x) Math.Exp(x)		// логарифмы
	Math.Ceiling(x) Math.Floor(x) Math.Round(x) // округление
	Math.Max(a, b) Math.Min(a, b)				// минимум/максимум

	Math.DivRem(a, b, out remainder)			// деление с остатком
	Math.Truncate(x)							// отбрасывание дробной части
	Math.Sign(x)								// знак числа
```

## 6. Прочие особенности синтаксиса выражений
### Метапрограммирование и generics
В C++ есть шаблонные выражения (compile-time)

```
	template<typename T>
	T max(T a, T b) { return a > b ? a : b; }

```
C# - generics с проверкой во время выполнения
```
	T Max<T>(T a, T b) where T : IComparable<T> 
	{ 
		return a.CompareTo(b) > 0 ? a : b; 
	}
```
### Вычисления времени компиляции
C++ - Constexpr функции (Вычисляется при компиляции)
```
	constexpr int square(int x) { return x * x; }
	constexpr int result = square(5); // 

	constexpr int factorial(int n) 
	{
		return n <= 1 ? 1 : n * factorial(n - 1);
	}
```
C# - Ограниченные const выражения.Применются только простые константные выражения. Нет constexpr функций - вычисления во время выполнения
```
	const int result = 5 * 5;

	int Square(int x) => x * x;
	int result = Square(5); // Runtime
```
C++ имеет мощные вычисления времени компиляции, C# - ограниченные константные выражения

### Лямбда-выражения и замыкания
C++ - Сложный захват с контролем времени жизни
```
	int x = 1, y = 2;
	auto lambda = [x, &y](int z) mutable 
	{ 
		x++; // Изменяет копию
		y++; // Изменяет оригинал
		return x + y + z; 
	};
```

C# - Автоматический захват с garbage collection
```
	int x = 1, y = 2;
	Func<int, int> lambda = z => 
	{
							// x и y захватываются автоматически
		return x + y + z;  // Нет mutable - все изменения видны внешне
	};
```
C++ требует явного указания способа захвата, C# автоматически управляет временем жизни
