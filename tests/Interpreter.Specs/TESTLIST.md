#Список тестов семантики

## Область видимости
**Позитивные тесты**
- [x] Функция видит переменные внешней области и может изменять их

**Негативные тесты**
- [x] Обращение к переменной вне её области видимости
- [x] Локальная переменная функции недоступна после её завершения

## Уникальность имён
**Позитивные тесты**
- [x] Перекрытие переменных
- [x] Параметр и внешняя переменная с одинаковым названием

**Негативные тесты**
- [x] Две переменные с одинаковым именем в одной области
- [x] Переменная и функция с одинаковым именем в одной области
- [x] Переменная с именем встроенной функции

## Параметры функций
**Позитивные тесты**
- [x] Передача параметров по значению
- [x] Функция без типа заканчивается без ДАРОВАТЬ
- [x] Функция без типа заканчивается ДАРОВАТЬ;
- [x] Функция без типа возвращает значение
- [x] Параметры функций вычисляются слева направо

**Негативные тесты**
- [x] Несоответствие количества параметров
- [x] Несоответствие типа параметра
- [x] Несоответствие порядка параметров
- [x] Функция с возвращаемым типом без ДАРОВАТЬ
- [x] Void-функция используется как выражение

## Рекурсия
**Позитивные тесты**
- [x] Функция вызывает саму себя
- [x] Две функции вызывают друг друга
- [x] Взаимная рекурсия в одной области видимости

**Негативные тесты**
- [x] Взаимная рекурсия в разных областях видимости

## Ветвления
**Позитивные тесты**

**Негативные тесты**
- [x] Небулево условие в ЕСЛИ
- [x] Отсутствие явного блока после СТАЛОБЫТЬ
- [x] Отсутствие явного блока после ИНО

## Цикл ПОКУДА
**Позитивные тесты**
- [x] Проверка условия перед каждой итерацией
- [x] Цикл не выполняется при ложном условии с начала

**Негативные тесты**
- [x] Небулево условие

## Цикл ДЛЯ
**Позитивные тесты**
- [x] Переменная цикла перекрывает внешнюю
- [x] Проверка выражений ОТ и ДО один раз

**Негативные тесты**
- [x] Нечисловой тип для границ цикла

## Операторы управления циклами
**Позитивные тесты**
- [x] ВЫЙТИ внутри цикла
- [x] ПРОДОЛЖИТЬ внутри цикла 

**Негативные тесты**
- [x] ВЫЙТИ вне цикла
- [x] ПРОДОЛЖИТЬ вне цикла

**Негативные тесты**
- [x] Присваивание литералу
- [x] Присваивание вызову функции
- [x] Присваивание выражению
- [x] Несовместимость типов при присваивании
- [x] Изменение типа переменной после объявления

- [x] Параметры функций считаются инициализированными
- [x] Переменная цикла ДЛЯ инициализируется значением ОТ
